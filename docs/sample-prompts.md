# Sample prompts for CareerBridge Academic

Copy any prompt, attach your own source files and adjust the details.

1. Verify this job posting and build an eligibility matrix against my CV.
2. Draft a cover letter for this faculty opening using only claims I can document.
3. Map this application portal's fields and tell me which ones exceed the character limits.
4. Create a research statement outline tailored to this department.
5. Prepare interview questions and a salary-negotiation plan for this offer.
6. Set up an application tracker and draft follow-up emails for the ones that are overdue.

Tip: attach the official source (posting, syllabus, methodology or CV) and say the exact output format you want. The agent works best when it can cite what you provided.
