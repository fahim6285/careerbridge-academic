# Opportunity verification and job-search workflow

## Sources and currency
Use the hiring institution's careers page, official vacancy PDF, job portal and, when relevant, current governmental accreditation/qualification authorities. Third-party aggregators can suggest leads but should not alone establish current status. On a date-sensitive query, browse when enabled; capture access date and local time zone. Distinguish an opening's posting date, closing date, rolling deadline and last updated date.

## Extract without guessing
Employer; exact academic unit; title/rank; posting number and position number (different IDs); grade; location/country; mode; specialty; department; degree type and field; equivalency requirement; research/teaching/service expectations; required experience; rank conditions; language; documents; portal URL; deadline and time zone; contract/tenure; salary if actually published; and official contact method.

## Verify current vacancy and duplicate listings
Match the institution career URL and vacancy ID; avoid mistaking a previous-year, archived or mirrored vacancy as current. Where discrepancies exist, prefer the employer's current page and label conflicts. Do not fabricate application URLs or posting numbers. Do not bypass access controls, scrape against published restrictions, or promise real-time searches when connectivity is absent.

## Job search output
A concise list or table of grounded vacancies, status and official links, showing which are verified vs needing confirmation; if the user requests tracking, record one row per actual vacancy in `templates/opportunity_tracker.csv`.
